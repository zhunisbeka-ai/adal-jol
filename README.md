# Adal Jol — Честный путь

Образовательная браузерная игра (визуальная новелла) о противодействии коррупции для студентов колледжей и вузов. Проект конкурса **ADAL URPAQ**, направление «IT-решение», Карагандинская область, 2026.

Игрок — первокурсник вымышленного Сарыаркинского политехнического колледжа. За один учебный год он сталкивается с ситуациями, знакомыми каждому студенту: «ускорить» заселение в общежитие, купить зачёт, скинуться «на подарок» преподавателю, «исправить» оценку, заплатить за пересдачу, купить справку о практике, подписать ложный акт на первой работе. Каждый выбор меняет репутацию, знания и деньги героя, отношения с персонажами — и ведёт к одной из пяти концовок.

После каждой главы открывается карточка «Что говорит закон»: разбор выбора игрока, нормы законодательства РК и контакты, куда обращаться (1424, eotinish.kz).

## Возможности

- **7 глав, 300 сцен, 14 развилок с 2–5 вариантами, 5 концовок** (включая секретную «Adal Urpaq») и эпилог о судьбах персонажей.
- **Последствия, которые помнятся**: решение из первой главы влияет на шестую. Персонажи помнят, как ты поступал, открываются и закрываются варианты.
- **Схема главы** после каждой главы: какие решения были, что выбрал игрок, какие пути ещё закрыты.
- **Два языка**: казахский и русский, переключение в любой момент.
- **Карточки законов** собираются в раздел «Что говорит закон» — справочник для игрока.
- **26 достижений**, сохранение прогресса, звук и музыка в духе домбры.
- Работает на телефоне и компьютере, без установки, без регистрации, без сервера.

## Файлы в репозитории

- `index.html` — вся игра одним файлом. Модули из раздела «Архитектура» собраны в него для простоты размещения: стили и скрипты встроены внутрь.
- `README.md` — это описание.

## Запуск

Открыть `index.html` в браузере. Для публикации — любой статический хостинг (GitHub Pages, Netlify и т. п.).

Управление на компьютере: пробел / Enter — дальше, цифры 1–5 — выбор варианта.

## Архитектура

```
index.html            — точка входа, подключает модули по порядку
css/style.css         — оформление (адаптивная вёрстка, тёмная тема)
js/engine.js          — игровой движок: состояние, переходы, условия, сохранение
js/art.js             — графика: фоны и портреты персонажей рисуются кодом (SVG)
js/audio.js           — звук: синтез через Web Audio API, без аудиофайлов
js/i18n.js            — тексты интерфейса на казахском и русском
js/ui.js              — экраны и взаимодействие с игроком
js/main.js            — запуск, клавиатура, разблокировка звука
story/characters.js   — персонажи
story/ch1.js … ch7.js — главы (каждая — отдельный файл)
story/meta.js         — достижения, концовки, эпилог
```

**Движок не знает ничего о сюжете.** Сценарий — это данные: каждая глава описана как граф узлов.

```js
c2_choice1: {
  who: 'timur', mood: 'sly',                    // кто говорит и с каким лицом
  text: { ru: '...', kk: '...' },               // текст на двух языках
  choices: [
    { text: { ru: 'Отдать 15 000', kk: '...' },
      effects: { money: -20 },                  // изменение шкал
      flags: { bought_exam: 1 },                // что игра запомнит
      add: { dirt: 1 },                         // счётчики для концовок
      remember: { ru: 'Тимур это запомнит', kk: '...' },
      next: 'c2_a1' },
    { if: 'friend_aidar', ... },                // вариант виден только при условии
  ],
},
c2_res: { type: 'branch',                       // условный переход
  cases: [{ if: 'bought_exam', next: 'c2_r_paid' }, { if: 'know >= 62', next: 'c2_r_good' }],
  else: 'c2_r_fail' },
c2_law: { type: 'law', ... },                   // карточка закона
```

Условия записываются мини-языком (`know < 40`, `bribe_dorm && !reported_dorm`), который движок разбирает сам, без `eval`.

**Типы узлов**: реплика, выбор, условный переход (`branch`), служебный (`set`), карточка закона (`law`).

**Состояние игрока**: три шкалы (репутация, знания, деньги), флаги решений, счётчики `dirt` (уступки коррупции) и `brave` (выступления против), история выборов. Хранится в `localStorage` браузера.

## Масштабируемость

- **Новая глава** — новый файл в `story/` и одна строка в `index.html`. Код движка не меняется.
- **Новая аудитория** (школьники, молодые специалисты, госслужащие) — новый набор глав в том же формате.
- **Новый язык** — добавить поле (например, `en`) в тексты; движок подставит его автоматически.
- **Без сервера**: игра — набор статических файлов, её можно разместить где угодно, открыть офлайн, встроить на сайт колледжа.
- **Пилот в учебных заведениях**: игру можно проходить на кураторском часе (15–25 минут), а карточки законов обсуждать с группой.

## Проверка качества

Сценарий проверяется автоматическим скриптом, который обходит все возможные пути игры (около 6 млн уникальных состояний):
- нет ссылок на несуществующие сцены и тупиков;
- каждая сцена, каждый вариант выбора, каждая концовка и строка эпилога достижимы;
- у каждого текста есть перевод на казахский и русский.

## Графика и звук

Вся графика (фоны, персонажи, орнамент «қошқар мүйіз») нарисована кодом, вся музыка и звуки синтезируются в браузере. Сторонних изображений и аудиозаписей нет — проект свободен от проблем с авторскими правами и весит около 320 КБ.

## Важно

Колледж, персонажи и события вымышлены. Правовая информация в карточках дана в упрощённом виде для образовательных целей и не является юридической консультацией. Актуальные нормы — в Законе РК «О противодействии коррупции» и Уголовном кодексе РК.
